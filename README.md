# Lead Management System - Backend API

A RESTful API for lead management built with **Node.js**, **Express**, **TypeScript**, and **MongoDB (Mongoose)**, structured following **Hexagonal Architecture** and Repository pattern principles.

---

## 🛠️ Tech Stack

* **Runtime:** Node.js
* **Framework:** Express.js
* **Language:** TypeScript
* **Database:** MongoDB with Mongoose ORM

---

## 🚀 Getting Started

### Prerequisites

* Node.js (v18 or higher)
* MongoDB running locally or a MongoDB Atlas connection string

### 1. Installation

Clone the repository and install dependencies:

```bash
git clone git@github.com:Antonio-Avelino/lead-management-back-end.git
cd lead-management-back-end
npm install

### 2. Environment Setup

Copy the `.env.example` file to create your `.env` configuration:

```bash
cp .env.example .env

# Development mode (with hot-reload)
npm run dev

# Production build
npm run build
npm start
